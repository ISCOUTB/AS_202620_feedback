## Estado de los repositorios

**Los 23 repositorios responden y son públicos.** Comprobado con `git ls-remote` y `git clone`,
las dos cosas **sin autenticación**, que es como los ve el evaluador desde fuera. La API sin token
está agotada para esta IP (403), así que los metadatos salen del protocolo git.

`AS_202620_PideUtb`, `AS_202620_ShareU`, `AS_202620_TRACTAR` y `AS_202620_XALD` no eran visibles en
la primera comprobación de este listado y ahora sí lo son. No eran repositorios nuevos: los cuatro
existían ya, con commits, así que estaban en privado. Queda anotado porque explica por qué una
revisión anterior pudo marcarlos como no visibles.

La visibilidad cambia sin avisar, de modo que **este apartado es una foto y no una garantía**: se
vuelve a comprobar antes de cada barrido.

```bash
# Estado de todos los repositorios del listado
for R in $(grep -oE 'AS_202620_[A-Za-z0-9_-]+' EQUIPOS.md | sort -u); do
  printf '%-52s %s
' "$R" "$(curl -s -o /dev/null -w '%{http_code}' "https://api.github.com/repos/ISCOUTB/$R")"
done
```

Si alguno vuelve a dar `404`, así se resuelve su ficha: un repositorio privado y uno inexistente
devuelven lo mismo sin token, luego el hallazgo se registra como **no visible**, no como «no
existe». El criterio de repositorio creado, público y con el nombre de la convención queda en **No
cumple** con el motivo, y el resto de la matriz en **No verificado** hasta que el equipo lo abra.
No se revisa a ciegas ni se pide acceso privado: el curso exige repositorio público.

```bash
# cuentas observadas frente a integrantes declarados, equipo por equipo
python - <<'FIN'
import io,re
s=io.open('EQUIPOS.md',encoding='utf-8').read()
eq=re.findall(r'^\| ([^|]+?) \| (`AS_202620_[^`]+`) \| ([^|]+) \|$', s, re.M)
integ={r.strip('`'):len([x for x in i.split('·') if x.strip()]) for _,r,i in eq}
sec=s.split('## Usuarios de GitHub vistos en el historial')[1]
for r,l in re.findall(r'^\| `(AS_202620_[^`]+)` \| (.+) \|$', sec, re.M):
    n=len(l.split('·'))
    if n < integ.get(r, 0): print(f'{r}: {n} cuentas / {integ[r]} integrantes')
FIN
```

## Cómo se usa en la revisión

1. Localiza el equipo en la tabla y toma su repositorio.
2. Contrasta las cuentas del historial con los integrantes de la tabla. Lo que falta se anota como
   nombre, no como cifra: «no aparece ninguna cuenta atribuible a X».
3. Si el repositorio no es visible, aplica lo del apartado de estado y no continúes con la matriz.
4. Lo que corrijas aquí (cambio de equipo, retiro, repositorio nuevo) se corrige también en el
   aula, o la próxima revisión volverá a partir del dato viejo.
